# Team Task Manager Backend

## Live URL
https://taskmanager-backend-production-36d9.up.railway.app

## Features
- User Authentication (Register/Login)
- Project Management
- Task Assignment & Tracking
- Role-based system (Admin/User)

## Tech Stack
- Spring Boot
- MySQL (Railway)
- JPA/Hibernate

## APIs

### Auth
POST /auth/signup  
POST /auth/login  

### Project
POST /projects  
GET /projects  

### Task
POST /tasks  
GET /tasks  

## Deployment
- Backend deployed on Railway
- Database: Railway MySQL

## How to run locally
1. Clone repo
2. Add DB config
3. Run Spring Boot app
